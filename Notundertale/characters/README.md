# Personnages originaux

Les quatre PNG transparents sont des sources de 32 × 48 pixels, agrandies sans
lissage à la même hauteur visible que le skin 2 (93 pixels actuellement), dans
un cadre de 100 × 100 pixels. Leurs proportions sont conservées. Ils ont été
créés avec l'outil intégré de génération d'images à partir
des concepts originaux du projet, puis cadrés et réduits au format du jeu.

- `remanent.png` : combinaison ivoire et parasite cyan.
- `scaphandre.png` : scaphandre massif rouillé et parasite ambre.
- `colonie.png` : combinaison turquoise et organisme violet.
- `deriveur.png` : squelette en combinaison cobalt, filaments vert pâle.

Le fond et les marges sont transparents. Le masque de collision utilise l'alpha
du sprite, pas le rectangle complet. Conserver ces propriétés pour les remplacer.
Les sprites ont pour l'instant une pose fixe orientée à droite ; le jeu les
retourne horizontalement pendant les déplacements vers la gauche.

Les références détaillées, les sources de génération et les prompts sont fournis
séparément avec les livrables artistiques du projet.
